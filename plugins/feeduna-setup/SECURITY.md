# Feeduna MCP security

## Supported releases

The current bundled connector is [`0.1.1`](https://github.com/performeon/feeduna-mcp/releases/tag/v0.1.1).
The published Codex and Gemini setup integrations use that connector source.

## Report privately

Send a private email to [thomas@performeon.com](mailto:thomas@performeon.com?subject=Feeduna%20security)
with the subject `Feeduna security`. Include the connector or plugin version,
your MCP host, the expected and observed behavior, and the smallest synthetic
example that demonstrates the issue. Use synthetic credentials and sample data.
Keep customer reports, screenshots and access keys private.

For testing, use an app and test records you own. If an access key may have
been exposed, revoke it in **App setup → Connect your tools**.
